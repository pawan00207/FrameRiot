## The Studio

FrameRiot brings the essential tools of a creator workflow into one focused,
installable web app. Shape your footage on a multi-track timeline, watch edits
as they happen, and export directly from your device.

### Edit with precision

- Multi-track video, audio, text, sticker, and effects timeline
- Split, trim, ripple delete, duplicate, freeze, reverse, mute, lock, and hide
- Snapping, beat markers, audio waveforms, and keyframe animation
- A responsive editor layout for desktop, tablet, and mobile

### Make every frame yours

- Real-time canvas preview with a broad collection of color filters and effects
- Transitions, chroma key, shape masks, and flexible aspect ratios
- Safe-area and composition guides
- Text overlays, typography, and animated captions

### Finish and deliver

- Import and export subtitle files
- Record and shape audio with the built-in browser audio tools
- Export video, audio, GIFs, and still frames at multiple resolutions
- Local project library with automatic saving and recovery
- Installable PWA with offline app-shell support

## Get started

### Requirements

- Node.js and npm
- A modern browser with Canvas, Web Audio, and MediaRecorder support

### Install

```bash
git clone https://github.com/pawan00207/FrameRiot.git
cd FrameRiot
npm install
```

### Run locally

```bash
npm run dev
```

### Build for production

```bash
npm run build
npm start
```

No account is required. Core editing and exports run in your browser.
